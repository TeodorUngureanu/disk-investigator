## Disk Investigator

Disk Investigator is a desktop application concept for low-level disk analysis and file recovery, developed as a bachelor's project at the Faculty of Computer Science, "Alexandru Ioan Cuza" University of Iași. It provides users with tools to scan internal and external drives, discover hidden files, recover deleted files, inspect directories and disk sectors, and monitor active system processes.

### Core Features

- **Disk Scan** — Scan a selected disk or partition in hexadecimal, decimal, or text mode, with real-time progress tracking and the ability to pause or stop mid-scan.
- **File Recovery** — Restore deleted files to a user-specified location, with partial recovery reporting if an error occurs.
- **File Management** — Browse scanned files and directories, view detailed metadata (path, size, type, permissions), and permanently delete files with confirmation prompts.
- **Process Scan & Management** — View and search active system processes, inspect resource usage (CPU, memory), and terminate running processes.
- **Search** — Filter files (regex-based) or processes (string-based) from within each module.

### Design Goals

The interface was designed to prioritize clarity and speed for both novice and experienced users: quick access to frequent actions, minimal redundant information, clear status/error feedback, and the ability to cancel any ongoing operation
